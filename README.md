# Sonority Sequencing Principle visualizator in JavaScript

This is a vizualizator of the Sonority Sequencing Principle on the example of the Croatian language (a language wth relatively lenient phonotactics, so the Sonority Sequencing Principle should apply strongly to it). `hr.wl` is the Aspell word-list for the Croatian language, released under the GNU LPL. It should be available on-line [here](https://flatassembler.github.io/sonority_sequencing_principle_visualizator/index.html).
